## Features Implemented

1. Signup (Mutation)
2. Login (Query)
3. Get All Employees
4. Add New Employee (with Cloudinary image upload)
5. Search Employee by ID
6. Update Employee
7. Delete Employee
8. Search Employee by Department or Designation

---

## How To Run

1. Install dependencies:
   npm install

2. Add .env file with:
   MONGO_URI=
   CLOUDINARY_CLOUD_NAME=
   CLOUDINARY_API_KEY=
   CLOUDINARY_API_SECRET=

3. Start server:
   node server.js

Server runs at:
http://localhost:4000/graphql
